# ML_training_2026

This repository explores the different techniques used to clean data, as well as how to understand and apply various machine learning (ML) techniques for exploratory data analysis after cleaning.

##  Table of Contents
- [Features](#-features)
- [Technologies Used](#%EF%B8%8F-technologies-used)
- [Getting Started](#-getting-started)
- [Project Structure](#-project-structure)

## Features
* **Data Cleaning:** Practical implementation of handling missing values, outliers, and data transformations.
* **Exploratory Data Analysis (EDA):** Utilising ML techniques to find patterns, correlations, and insights post-cleaning.

## Technologies Used
* **Python 3.10+**
* **Pandas** & **NumPy** (Data manipulation)
* **Scikit-learn** (Machine learning algorithms)
* **Matplotlib** & **Seaborn** (Data visualization)
